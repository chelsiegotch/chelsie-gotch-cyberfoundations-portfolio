**What is the cybersecurity landscape, and why does it matter?**

```
The cybersecurity landscape is made up of three main parts: the threat environment, the attack surface, and the defense systems. All three of these parts work together to help protect people, systems, and data from cyber attacks. It is a dynamic landscape that is constantly changing as threats and threat actors evolve. The cyber landscape matters because, as a cybersecurity specialist, my job will be to monitor systems, detect threats, and keep that entire environment as secure as possible.
```

**How do hardware, OS, and software layers interact?**

```
The software layer is what the end user directly interacts with. When a user performs an action in an application, the software cannot access physical components directly, so it sends requests down to the operating system as system calls. The OS processes those calls and translates them into commands and instructions for the hardware. The hardware executes the task and sends signals or interrupts back up to the OS, which then delivers the resulting data back up to the software layer for the user to see.
```
