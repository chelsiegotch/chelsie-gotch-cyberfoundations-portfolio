## In My Own Words

**What's the difference between a file and a folder, and how do they form a tree together?**

```
A file is an individual item that actually holds your data or text, while a folder is basically a container used to organize and store files. They form a tree together because folders can hold other folders inside them along with files, creating branches and layers that branch outward from a main root directory.

```

**How does a Windows-style file path differ from a Linux-style file path?**

```
A Windows-style file path uses drive letters like C:\ at the very front and backslashes to separate folders, while a Linux-style file path starts directly from a root directory using forward slashes without any drive letters.

```

**One command from this week you feel most confident with — and why?**
